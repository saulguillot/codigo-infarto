# Cardio CMN 20 · Código Infarto

Web app estática para GitHub Pages.

## Publicación
1. Crear/subir estos archivos a un repositorio de GitHub.
2. Configurar GitHub Pages para publicar desde `main` y `/` (root), o mediante GitHub Actions.
3. Abrir la URL publicada en Safari.
4. En iPhone: Compartir → Añadir a pantalla de inicio.

## Nota
El sitio es un prototipo clínico y no sustituye protocolos institucionales ni validación de seguridad, privacidad y gobernanza de datos.
